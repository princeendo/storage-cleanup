# Local Page Implementation Plan (Build Step 2 of 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `uv run storage-cleanup serve` opens a local, read-only web page that
shows a scan: headline numbers, a drill-down "where did my disk go" treemap
through the category lens and the location lens, the reclaim-zone scatter,
and dead weight in your projects.

**Architecture:** Python does all the arithmetic. `web/views.py` turns a
`Scan` into one page-ready JSON document: partition trees whose numbers add up
to the disk's used space, scatter points, and project rows. `web/server.py` is a
standard-library HTTP server bound to `127.0.0.1` that requires a per-session
token and serves that JSON plus static files. The browser side is plain HTML,
CSS, and ES modules with vendored ECharts. It only renders, so almost every
behavior is tested in Python.

**Tech Stack:** Python 3.12 standard library (`http.server`, `importlib.resources`,
`secrets`, `webbrowser`); HTML/CSS/JavaScript ES modules, no build step;
Apache ECharts 5.6.0 vendored as one file.

**Spec:** `docs/superpowers/specs/2026-11-05-storage-explorer-design.md`
(sections 6.1, 6.2, 9 "Local server safety", 10, 11 step 2). Builds on the
scanner (`docs/superpowers/plans/2026-11-05-scanner.md`); the scan file format
is `storage_cleanup.scan.model`.

## Review Focus

1. **Hostile file names** such as `<img src=x onerror=alert(1)>.txt`, `&amp;`,
   or quotes. They must show as text in every tooltip, label, table, and
   detail panel and never run anything (Tasks 5–8, checked in the browser
   with a planted file).
2. **Another program or web page reading the scan.** A request without the
   token, with a wrong token, or with a foreign `Host` (DNS rebinding) gets
   `403` (Task 3).
3. **Large scans** (this Mac has about 1,500 items, and a busier home folder
   could have 20,000). Small children are grouped so the treemap stays
   readable and fast (Task 1).
4. **Sparse or odd scans**: no projects, Docker not running, unreadable Trash,
   zero items, children whose sizes add up to more than their parent. These
   give empty states and non-negative numbers, never errors (Tasks 1, 2, 5).
5. **A missing, corrupt, or newer-schema scan file**: `serve` exits with a
   clear message instead of a traceback (Task 3).

### Task 1: Partition trees (category and location lenses)

**Files:**
- Create: `src/storage_cleanup/web/__init__.py`, `web/views.py`
- Test: `tests/web/__init__.py`, `tests/web/test_views.py`

**Interfaces:**
- Consumes: `Scan`, `Item`, `ItemKind`, `DISPLAY_NAMES`, category constants.
- Produces:

```python
CATEGORY_PRECEDENCE: Final[tuple[str, ...]] = (
    AI_TOOLING, DOCKER, APPLICATIONS, LEFTOVER_APP_DATA, APP_DATA, HOMEBREW,
    PACKAGES, DEV_CACHES, PROJECTS, DOWNLOADS, HOME,
)
SYSTEM_OTHER: Final = "system-other"   # display: "macOS and everything not scanned"
OTHER_LOCATIONS: Final = "Other locations"
DOCKER_DISK: Final = "Docker virtual disk"
SMALL_MIN_BYTES: Final = 64 * 1024**2
SMALL_FRACTION: Final = 0.005

@dataclass
class TreeNode:
    id: str
    name: str
    value: int
    kind: str                 # "group" | "item" | "rest" | "smaller" | "system"
    group: str                # category ID or location label this node belongs to
    path: str | None = None
    children: list["TreeNode"] = field(default_factory=list)
    def to_json(self) -> dict[str, JsonValue]   # omits empty children

def primary_category(item: Item) -> str          # first of CATEGORY_PRECEDENCE present, else HOME
def exclusive_sizes(items: Sequence[Item]) -> dict[str, int]
    # id -> max(0, size - sum(direct children sizes)); children via parent_id
def category_groups(items: Sequence[Item]) -> dict[str, str]   # id -> category group (step 1 below)
def category_tree(scan: Scan) -> TreeNode
def location_tree(scan: Scan) -> TreeNode
```

Algorithm (shared by both trees; write it once as
`_partition(scan, own_group, weak_group, fallback, display) -> TreeNode`):

1. Each item's **group**: category tree uses `primary_category`; `HOME` is
   *weak*, so an item whose primary is `HOME` takes its nearest ancestor's
   non-weak group, else stays `HOME`. Location tree uses `item.location`; an
   item with `None` takes its parent's group; a top-level item with `None`
   gets `DOCKER_DISK` if `DOCKER` is in its categories, else `OTHER_LOCATIONS`.
2. A **group root** is an item whose parent is `None` or whose parent is in a
   different group.
3. `node(item)`: children are `node(c)` for direct children `c` in the same
   group. If it has such children and `exclusive_sizes[item.id] > 0`, add a
   leaf `kind="rest"` named `"Other files in <name>"` with that value. Its
   value is the exclusive size plus the sum of its children's values. Bytes of
   children in another group are counted in that group, never twice.
4. Root `name="Disk used"`, `value=scan.disk.used_bytes`, `kind="group"`.
   Its children are one `kind="group"` node per group (value = sum of its
   group roots' values, display name from `DISPLAY_NAMES` for categories or
   the label for locations), sorted by value descending. Then add one
   `kind="system"` node for `SYSTEM_OTHER` with
   `max(0, used - sum(groups))`.
5. **Grouping of small children** at every level: when two or more children
   have a value below `max(SMALL_MIN_BYTES, SMALL_FRACTION * used)`, replace
   them with one leaf `kind="smaller"` named `"<n> smaller items"` with their
   summed value.
6. Node IDs: item nodes use the item ID; group nodes `group:<group>`; rest
   nodes `rest:<item id>`; smaller nodes `smaller:<parent id>`.

### Task 2: Scatter points, project rows, overview, and `build_view`

**Files:**
- Modify: `src/storage_cleanup/web/views.py`
- Test: `tests/web/test_views.py`

**Interfaces:**
- Produces:

```python
SCATTER_MIN_BYTES: Final = 10 * 1024**2
RECLAIM_ZONE: Final = {"min_bytes": 1024**3, "min_age_days": 365}

def scatter_points(scan: Scan, now: float) -> list[dict[str, JsonValue]]
def project_rows(scan: Scan, now: float) -> list[dict[str, JsonValue]]
def overview(scan: Scan) -> dict[str, JsonValue]
def build_view(scan: Scan, now: float) -> dict[str, JsonValue]
```

`scatter_points`: one point per item that has an age and `size >= SCATTER_MIN_BYTES`, and either
(a) its kind is not `folder`/`file`, or (b) it is a direct child of the home
folder, or (c) it is a direct child of `~/Downloads`. Fields: `id`, `name`,
`path`, `size`, `age_days` (`(now - age_timestamp) / 86400`, floored at 0),
`age_signal`, `category` (the item's group in the category tree),
`protected` (bool), `in_zone` (size and age at or above `RECLAIM_ZONE`).

`project_rows`: one row per `repo` item, sorted by `regenerable_bytes`
descending, then size. Fields: `id`, `name`, `path`, `size`,
`regenerable_bytes`, `own_bytes` (`max(0, size - regenerable)`),
`last_commit_days` (`None` if the age signal is not `last-commit`), `dirty`,
`unpushed_commits`, `has_remote`.

`overview`: `used_bytes`, `free_bytes`, `total_bytes`, `percent_free` (one
decimal), `created_at`, `trash_bytes` (may be `None`), `local_snapshots`
(count), `skipped` (list of `{path, reason, collector}`), `item_count`.

`build_view`: `{"schema": 1, "overview": ..., "categories": category_tree(...).to_json(),
"locations": location_tree(...).to_json(), "scatter": ..., "projects": ...,
"reclaim_zone": RECLAIM_ZONE, "category_names": DISPLAY_NAMES | {SYSTEM_OTHER: "macOS and everything not scanned"}}`.
Strings pass through unchanged. Escaping is the browser's job (Review Focus 1).

**Files:**

- Modify: `src/storage_cleanup/cli.py`, `tests/test_cli.py`

**Interfaces:**
- Consumes: `build_view`, `scan_from_json`, `latest_scan`.
- Produces:

```python
TOKEN_COOKIE: Final = "sc_token"
def make_server(scan_path: Path, *, port: int = 0, token: str | None = None
                ) -> tuple[ThreadingHTTPServer, str]      # (server, token); bound to 127.0.0.1
def page_url(server: ThreadingHTTPServer, token: str) -> str   # http://127.0.0.1:<port>/?token=<token>
def serve(scan_path: Path, *, port: int = 0, open_browser: bool = True) -> None
    # load-checks the scan first (raises ValueError with a readable message), prints the URL,
    # opens it with webbrowser unless open_browser is False, serves until Ctrl-C
```

Request rules (handler built inside `make_server`, static files read with
`importlib.resources.files("storage_cleanup.web") / "static"`):

| Request | Response |
| --- | --- |
| `Host` not `127.0.0.1:<port>` or `localhost:<port>` | `403` |
| `GET /?token=<right>` | `302` to `/`, sets `sc_token=<token>; HttpOnly; SameSite=Strict; Path=/` |
| any request without the right cookie (`secrets.compare_digest`) | `403`, body `Open the link printed by "storage-cleanup serve".` |
| `GET /` | `index.html` |
| `GET /static/<name>` | the file if it resolves inside `static/`, else `404`; `Content-Type` by extension (`.js` → `text/javascript`) |
| `GET /api/view` | `build_view(scan, time.time())` as JSON, `Cache-Control: no-store`; the scan file is re-read on each request |
| any non-`GET` | `405` |

Every response carries `Content-Security-Policy: default-src 'self'; script-src 'self';
style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self';
frame-ancestors 'none'; base-uri 'none'`, `X-Content-Type-Options: nosniff`,
and `Referrer-Policy: no-referrer`. (`'unsafe-inline'` styles are needed
because ECharts tooltips use inline style attributes. Scripts stay `'self'` only.)
The handler's `log_message` is silenced.

CLI: `storage-cleanup serve [--scan FILE] [--output-dir reports/scans] [--port N] [--no-open]`.
Default scan = `latest_scan(output_dir)`. Exit `2` with
`No scan found. Run "storage-cleanup scan" first.` when there is none, and
exit `2` with `Cannot read scan <path>: <reason>` for an unreadable, corrupt,
or wrong-schema file.
