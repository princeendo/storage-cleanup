# Scanner Implementation Plan (Build Step 1 of 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `uv run storage-cleanup scan` measures where disk space is on this Mac
(all six of Colin's blind spots) and writes one JSON scan file under
`reports/scans/`, changing nothing else on disk.

**Architecture:** Independent *collectors* (home folders, Downloads, apps,
AI tools, Homebrew and other packages, Docker, developer caches, projects)
each return measured `Item`s. `run_scan` runs them all, catches any collector
failure as a `Skipped` record, joins path items into one containment tree,
marks protected paths and location labels, and the store writes the result
atomically. External commands go through an injectable `Runner`, so tests
never touch real Docker, Homebrew, or Spotlight.

**Tech Stack:** Python 3.12 standard library only; pytest, ruff, mypy (strict)
through `uv`.

**Spec:** `docs/superpowers/specs/2026-11-05-storage-explorer-design.md`
(sections 4, 9, 10, 11). Later plans (page, agent playbook, delete, archive,
target mode) consume the scan file this plan defines.

## Global Constraints

- Python `>=3.12`; no runtime dependencies (`dependencies = []` stays empty).
- Everything through `uv`: `uv run pytest`, `uv run ruff check .`,
  `uv run ruff format .`, `uv run mypy` (strict, covers `src` and `tests`).
- The scanner is read-only. It writes only the scan file. No `sudo`, no Full
  Disk Access request, no Time Machine, Spotlight, or system setting changes.
- Size is allocated blocks on disk (`st_blocks * 512`); hard links count once.
  Sizes reported by a tool (Docker) are marked `size_source="tool-reported"`.
- Paths the scanner cannot read become `Skipped(..., reason="no access")`.
- `~/Library/Containers` and `~/Library/Group Containers` are not walked
  unless `--include-app-data` is passed; they are recorded as
  `Skipped(reason="privacy-protected app data (not scanned)")`.
- Scan files contain real paths and live under `reports/` (git-ignored).
- Tests use `tmp_path` and `FakeRunner` only. No test runs real `docker`,
  `brew`, `mdls`, or `tmutil`. Real `git` inside `tmp_path` is allowed.
- Commit identity must be `13876322+princeendo@users.noreply.github.com`
  (check `git config user.email` before the first commit). Commit messages end
  with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Symlinks**, including loops and links pointing outside the home folder:
   never followed, never counted twice, never hang the walk (Task 2).
2. **Files that vanish or lose permission mid-walk**: the walk records or
   ignores them and keeps going (Task 2).
3. **Odd file names** (spaces, newlines, emoji, decomposed Unicode): survive
   measurement and a JSON round trip unchanged (Tasks 1 and 2).
4. **Missing or failing tools** (Docker not running, no Homebrew, `mdls`
   printing `(null)`, a collector raising): the scan still finishes and says
   what it skipped (Tasks 4, 9, 10).
5. **Sparse files** (Docker's disk image is the real-world case): reported
   at allocated size, not apparent size (Task 2).

```python
@dataclass(frozen=True)
class Measurement:
    size_bytes: int; file_count: int
    newest_mtime: float | None; oldest_mtime: float | None

type SkipRule = Callable[[Path], str | None]   # returns a skip reason or None

def measure_tree(root: Path, *, collector: str, max_item_depth: int = 0,
                 min_item_bytes: int = 0, skip: SkipRule | None = None,
                 ) -> tuple[dict[Path, Measurement], tuple[Skipped, ...]]
def measure(path: Path, *, collector: str, skip: SkipRule | None = None,
            ) -> tuple[Measurement, tuple[Skipped, ...]]   # = measure_tree(path)[root]
```

`measure_tree` walks once with `os.scandir` and `lstat`, never follows
symlinks (a symlink counts its own blocks only), never crosses into another
device (`st_dev` differs from the root's), counts each `(st_dev, st_ino)` with
`st_nlink > 1` once, and sums bottom-up. It returns the root plus every
descendant at depth `<= max_item_depth` whose size is `>= min_item_bytes`.
`PermissionError` on a directory → `Skipped(path, "no access", collector)`;
`FileNotFoundError` mid-walk → ignored silently. A path the `skip` rule names
is not entered and is recorded as `Skipped(path, reason, collector)`.
Directories count their own blocks too. The walk is iterative (explicit
stack), not recursive, so deep trees cannot hit the recursion limit.

Protected (spec section 9 and AGENTS.md rule 5), returned reason strings in
parentheses:
- `/System`, `/bin`, `/sbin`, `/usr` but not `/usr/local`, `/private/var/db`,
  `/Library/Apple` and anything below ("system location").
- Any path with a component ending in `.photoslibrary` ("Photos library").
- `~/Library/Mail` ("Mail"), `~/Library/Messages` ("Messages"),
  `~/Library/Keychains` ("Keychains"), `~/Library/Mobile Documents`
  ("iCloud Drive").
- Any component ending in `.backupbundle` or `.sparsebundle`, or named
  `Backups.backupdb`, or any path under `/Volumes/.timemachine` ("Time Machine").
- Any path that has a `.git` component, including the `.git` folder itself
  ("inside a .git folder"). A repository root is **not** protected by this
  rule (spec section 9, Colin's decision).

Paths are compared after `os.path.abspath` (no symlink resolution) and are
case-insensitive (APFS default).

Location labels: longest matching prefix wins:
`("Downloads", "Downloads")`, `("workspace/personal", "Your personal data")`,
`("workspace", "Workspace")`, `("Library", "Library")`,
`("Documents", "Documents")`, `("Desktop", "Desktop")`. Any other path under
home → the first component under home (for example `"Movies"`, `".cache"`).
`/Applications/...` → `"Applications"`. Under the Homebrew prefix
(`/opt/homebrew` or `/usr/local/Homebrew`/`/usr/local/Cellar`) → `"Homebrew"`.
Anything else → `None`.

`link_tree` rules:
1. Items with the same `path` merge into one: keep the item whose `kind` is
   not `folder`/`file` (the more specific collector), union `categories` in
   first-seen order, merge `details` (specific item wins on key clashes), and
   keep its `id`.
2. A path item with no `parent_id` gets the ID of the nearest ancestor path
   item (by path prefix on component boundaries). Items that already have a
   `parent_id` (virtual items) keep it.

`category_totals`: for each category, sum `size_bytes` of items in that
category that have no ancestor (following `parent_id`) in the same category.
`location_totals`: the same rule using `location`. These two rules are what
stop double counting when the home walk and a specific collector both
measure `~/Library/Caches/Homebrew`.

`run_scan`: runs each collector; an exception becomes
`Skipped(path="", reason=f"collector failed: {type(exc).__name__}: {exc}", collector=name)`
and the scan continues. Then `link_tree`, then set `location` and
`protected_reason` on every path item, then totals. Disk usage is
`shutil.disk_usage(ctx.home)` with `volume="/"`. `trash_bytes` is
`measure(home/.Trash)`, or `None` with a `Skipped(..., "no access", "trash")`
when it raises `PermissionError` (normal without Full Disk Access).
`local_snapshots` is the non-empty lines of `tmutil listlocalsnapshots /`
that start with `com.apple.`; a non-zero exit gives `()` and a `Skipped`.
`created_at` comes from `ctx.now`.
